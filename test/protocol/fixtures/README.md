# Protocol fixture provenance

The independent reference implementation is the React Native client at commit
`6e606f4cea213f2b7810c43c7f3376037932b337` in this repository. Its generated Codama
client lived under `src/lib/generated/twob/src/generated`, and its Anchor IDL at
`src/lib/idl/twob_anchor.json`. The IDL is preserved verbatim at
`idl/twob_anchor.json` (SHA-256
`2c3cd5ef2439b77168df6c83feb74b7fbe0b3db328220a2214e64b1ec37f26fa`).

`mainnet-market.json` was copied unchanged from the baseline's
`src/features/trading/api/fixtures/mainnet-market.json`. It records the deployed
SOL/USDC market at slot 453870292. Its SHA-256 is
`c019594fd54e581decc803263037f6caeb3b89e77c203f58d9fd623e55d6d03e`.

`codama-reference.json` was generated by executing the original generated
TypeScript instruction builders, PDA derivation, account encoders and event
encoders through `@solana/kit` 6.5.0. No Dart code generated its expected bytes.
It contains six instruction account lists/roles and byte payloads, full-width
integer account fixtures, deterministic PDAs, and close/fee event payloads. Its
SHA-256 is `1b68d931d14790bf1f23e449fb44b5f619f7a230a3b96fa8fad691d542c06e1a`.

Flutter tests read the checked-in JSON directly. Node and TypeScript are not
required to build the app or run its tests. `idl_consistency_test.dart` separately
interprets the preserved IDL and checks every implemented field layout,
instruction argument, discriminator, account order and signer/writable privilege,
so updating an IDL without updating the Dart protocol fails tests.

To regenerate the independent fixtures, check out the baseline commit in a
separate checkout, install its locked dependencies with pnpm, create
`test/protocol/fixtures`, save the following historical generator as
`test/protocol/generate_reference_fixtures.mjs`, and run
`node test/protocol/generate_reference_fixtures.mjs` from that checkout. This used
Node 26.8.1 and TypeScript 5.9.3. Inspect changed bytes before replacing fixtures;
do not derive golden values from the implementation being tested.
